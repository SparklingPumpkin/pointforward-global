# VR-v1-b：前馈后950步全程联合优化

不执行“全场景350步后冻结静态与U-Net再训车”的切换。静态与动态Gaussian、U-Net、车辆轨迹从第1步到第950步使用同一个AdamW；350/550/750/950仅是观察点，保存和评估后继续原优化器。

## 初始化与参数

初始化仅使用FFR-v1-z正式run的原始前馈载荷及通用20k检查点。未读取scene350、旧车辆训练结果、适配U-Net或旧optimizer。8,596,883个静态Gaussian、450,000个动态Gaussian均优化完整128D feature、XYZ、scale、rotation、opacity、time、sigma；网络仅训练U-Net，通用深度/图像/融合网络冻结。车辆轨迹优化每4帧一个控制结点的平移和yaw，canonical参考位姿固定。车辆ID、原始评估bbox、相机标定、点数和构建时source RGB固定。

全图目标为各相机log-MSE均值，叠加0.25倍strict逐车均衡ROI log-MSE、0.02倍轨迹修正平滑及1e-4增量锚定。所有950步使用同一公式。静态学习率/边界沿用旧scene350：feature .03/±.5、XYZ .02/每轴±.02m、log-scale±.25、旋转5°、opacity logit±.5；动态feature LR .006/±1、几何LR .004/XYZ每轴±.3m、log-scale±.7、旋转20°、opacity LR .004/±2；U-Net LR .0002、pose LR .001/每轴±.5m和yaw±15°。240、700步所有LR乘0.4，不改变可训练集合。

因此与旧分阶段训练不是仅改变顺序的单因素对照：全程保留ROI监督、动态较大修正范围及低LR，并持续训练静态/U-Net。若有收益，支持该整套联合配置有效，不能把收益全部归因于取消冻结。

计算实现也有差异：本轮三相机在同一渲染图中直接反传全图及逐ROI log-MSE；旧车辆阶段先做三相机no-grad渲染，再逐相机重渲染反传，包含重复渲染。本轮峰值显存更高，耗时差异不能只归因于训练顺序或取消冻结。

初始球形Gaussian的rotation梯度，以及大sigma下time/sigma梯度接近零。它们在优化器中，但并不意味着各参数都对指标有显著贡献。首步与检查点梯度、实际参数改变量分别保存于loss_steps.jsonl、parameter_changes.json。

## 时间与趋势

最终950步交付PLY和视频的本次实际增量2065.830s（34.431min）。加回原始前馈及其视频前缀442.946s后，历史累计2508.776s（41.813min）。这是跨run历史账目，未验证新的一次RGB冷启动。未加回舍弃的scene350或车辆优化，也没有漏掉前馈时间。所有中间检查点评估和保存均已包含；早期检查点只有载荷/网络/视频，PLY在950步后导出。

训练进程内初始化、训练及最终保存总计2052.954s；其中检查点保存与评估756.254s。峰值CUDA allocation 67.106GiB。不同时间段随机帧组成不同，短窗口MSE不能直接替代完整固定帧PSNR。

## 人工视觉审查

已亲自查看第60、110、140帧同位置车辆裁剪、350/550/750/950检查点和旧scene350、VR-v1-a、历史y对照，以及全局/动态PSNR和正值MSE曲线。后期背景道路、建筑边缘和小车轮廓更稳定，黑色皮卡轮廓有改善；第140帧近处SUV的窗框、车门及轮胎仍明显模糊，部分车身边缘仍有颗粒，不能声称已解决车辆细节问题。950步全局30.294842、动态26.334712dB，相对旧同950步提高1.928848/1.755642dB；动态比历史y提高1.003704dB。750至950仍增加0.459758/0.464594dB，但边际收益已低于前200步。动态bbox指标包含框内背景，部分改善可能来自持续训练的静态和U-Net，不能等价为车辆表面单独提高同样dB；也未做仅改变冻结顺序的单因素归因。

正式质量属于128D Gaussian + 本检查点U-Net + 保存的车辆轨迹 + 固定source RGB blend=.75的源视角重建，不是新视角泛化指标，也不是单独preview PLY的质量。PLY为frame000标准预览；准确复现需要对应runtime payload、meta与refiner_state。
