## 方法和本轮自检修订

保留上一轮实际选择的原始点池、原始点ID、LiDAR/bbox独立帧偏移及车辆列表；已有18个源帧不满足统一偏移的观测继续剔除，不用当前帧代替缺失相邻扫描。

点归属使用±250ms时间可行域，在同一时间假设下同时满足车辆3D范围与RGB轮廓约束；体素0.12m、连通半径0.27m，保留有支持的多个分量，不把整个邻近分量一概纳入。可靠mask缺失的车仍做几何拟合，图像对齐质量明确为未验证。

初次亲查9张归属总图后，又查看各批删点比例最高的两帧。发现Argo017 ID24 f4原本33点只保留3点，其中有明显轮廓支持点被过严的3D/连通条件排除。因此增加稀疏观测（原点池≤128点）的逐点保守保护：旧位置下距mask≤1px、在1.5倍旧框附近的点保留。其余密集观测只有整帧原来较可靠时才沿用旧结果保护。旧拟合保护是约束设计，100%保留率不能冒充独立真值验证。

曾试过不区分稀疏/密集的逐点保护，但亲查发现它把ID66旧拟合误移进轮廓的街景点带回，故撤回到上述保守密度分支。中间证据保存在first_time_fit_evidence.zip、before_pointwise_protection_evidence.zip、unrestricted_pointwise_protection_evidence.zip，不覆盖历史P/Q。稀疏保护阈值是本轮经验配置，尚未证明可泛化到所有距离和传感器。

时间模型对每辆车i和数据流s分别使用：

`tau_i,s = tau_scene,s + delta_i,s`

`P_camera = A_i(t_camera) @ inverse(A_i(t_actual_source + tau_i,L)) @ P_source`

`B_camera = A_i(t_camera) @ inverse(A_i(t_actual_bbox + tau_i,B)) @ B_source`

共享时间限±200ms；单车残差限±60ms，且加权均值严格为0，消除共享量与残差的自由度。同一物理场景的三组车辆合并拟合一个共享值。LiDAR与bbox时钟分开拟合。时钟是对当前轨迹/标注/投影模型的有效修正，**不是已验证的硬件同步延迟**。时间曲线粗网格5ms，局部±8ms细化为0.5ms；每观测最多1800点拟合，最终指标评估全部保留点。

小空间偏置最后独立评估；点偏置局部轴界限为(0.12,0.08,0.04)m，bbox中心偏置为(0.15,0.12,0.08)m。要求有足够图像改善且好帧不明显退化才采用。本轮42辆车中点偏置采用12辆、bbox偏置采用1辆，详细值见各批calibration.json。小偏置仍无法挽救所有空间错配，不扩大边界以包装成功。

## 指标

距离单位为768×576输入分辨率的像素，是点到自动轮廓外部的单向距离，落在轮廓内部记0。先逐观测求均值，再对有可靠图像证据的观测平均。它不衡量覆盖完整性、真实物理校准或3D框精度，低值不能替代肉眼检查。

“旧全池”与“最终”点数量不同，不可将差值全算作时间收益；“旧同点”只在本轮保留点上评估旧位置；“归属未调时→仅时间”隔离时间阶段；“时间原全池”对未删点的同一原始点池只施加本轮时间模型。完整包含率、外溢>3px比例与框mask IoU均在evaluation.json内。

## 复现、计时与保留

源码和依赖快照见code_provenance.json；配置config.json，入口reproduce.sh。输入/缓存依赖见input_manifest.json；原始扫描一致性与点池完整性见delivery_audit.json。旧P/Q及其上游mask/点池/适配器仍是受保护依赖，均未更改或删除。复现材料已核对，本轮确实多次执行，但未另做一次无缓存冷启动复现。

ownership_timer.json和fit_timer.json只记录**复用历史点池与mask后的阶段耗时**；同场景三批共享一次拟合，不能把三个fit_timer相加，也不能把它们称为从原始传感器数据开始的完整时间。多次自检修订的日志单独保留，不报告为单次算法延迟。

本轮产物标记keep：诊断图、原点池、剔除点、失败及修订证据仍有明确复核价值，没有执行删除，也不将旧实验误列为无价值。
